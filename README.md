# Advanced AI-Driven Scientific Manuscript Generation Framework

A generic operating framework for AI research assistants (Claude, DeepSeek or similar) that support an experimental + computational materials-science project, from raw data to a journal-ready manuscript.

**`FRAMEWORK.md`** is the whole framework in one file. It covers:
- mission and priorities;
- how to think before acting;
- hard rules: scientific integrity, file safety, ask-first actions, figure and text standards;
- the work loop: scope → backup → build → multi-lens review → adversarial verification → fix → recheck → report;
- communication style;
- tested Windows tool recipes: Word COM, EndNote temporary citations and custom styles, Origin, VESTA isosurfaces, ChemDraw, DFT/HPC practice;
- verification code for manuscripts;
- lessons learned;
- journal formatting checklist;
- writing and simulation-reporting standards;
- start-of-session checklist.

## Use

1. Copy `FRAMEWORK.md` into your assistant's standing instructions (`CLAUDE.md`, `AGENTS.md`, system prompt or project instructions).
2. Replace the `<placeholders>` with your own paths, palette, target journal and results file.
3. Keep the hard rules.
